# Changelog

## deckroadmap 0.1.4

CRAN release: 2026-04-21

- Initial CRAN release.
- Added section-aware roadmap footers for ‘Reveal.js’ slides.

### deckroadmap 0.1.1

- Added
  [`preview_roadmap()`](https://codingtigertang.github.io/deckroadmap/reference/preview_roadmap.md)
  to preview roadmap styles before rendering slides.
- Improved roadmap customization behavior across built-in styles.
- Refined progress-style rendering and related visual behavior.
- Updated documentation and examples.

### deckroadmap 0.1.0

- Initial release.
- Added
  [`use_roadmap()`](https://codingtigertang.github.io/deckroadmap/reference/use_roadmap.md)
  for section-aware roadmap footers in Reveal.js slides.
- Added support for Quarto Revealjs and R Markdown Revealjs.
- Added multiple built-in styles: `pill`, `minimal`, and `progress`.
- Added options for section colors, footer size, and bottom positioning.
